## Service area sources

The intervention polygon is a geodesic 50 km circle centred on Valenciennes, intersected with France's boundary using Turf. It is a cartographic approximation, not a legal boundary survey.

- France boundary: Natural Earth, 1:10m admin 0 countries, public domain. https://www.naturalearthdata.com/about/terms-of-use/
- Source geometry: https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_0_countries.geojson
- French town names and centres: https://geo.api.gouv.fr/communes (departments 59, 62 and 02), French public geographic data, Licence Ouverte. Positions within 50 km are selected for display.
- Prepared on 3 November 2026. Geometry and commune data are stored locally to avoid runtime geographic API requests.
